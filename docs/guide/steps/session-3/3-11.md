# 3-11 시트 읽고 쓰기

이 문서는 3-11 프롬프트에만 적용합니다. 시트 만들기와 사진 저장 기능은 각각 해당 단계에서 다룹니다.

## 구현 보충

- `doPost`의 기존 `setup`은 유지하고 `read`, `append`, `update`를 추가합니다. 다음 단계의 사진 작업은 미리 추가하지 않습니다.
- 세 작업은 먼저 `getConfiguredSpreadsheet()`를 불러 `SHEET_ID`와 `FOLDER_ID`가 설정돼 있는지 확인합니다. 둘 중 하나가 없거나 해당 Google 파일을 열 수 없으면 `시트와 사진 폴더가 아직 없습니다. npm.cmd run gas:init을 실행하세요.`를 반환합니다.
- 이 검사는 사용자가 읽을 오류 문장으로 보내도록 오류에 `userMessage`를 붙이는 `createUserError(message)`를 함께 둡니다. 같은 함수가 이미 있으면 중복 정의하지 않고 기존 함수를 사용합니다.

```javascript
function getConfiguredSpreadsheet() {
  const properties = PropertiesService.getScriptProperties();
  const spreadsheetId = properties.getProperty('SHEET_ID');
  const folderId = properties.getProperty('FOLDER_ID');
  if (!spreadsheetId || !folderId) {
    throw createUserError('시트와 사진 폴더가 아직 없습니다. npm.cmd run gas:init을 실행하세요.');
  }
  try {
    DriveApp.getFolderById(folderId);
    return SpreadsheetApp.openById(spreadsheetId);
  } catch (error) {
    throw createUserError('시트와 사진 폴더가 아직 없습니다. npm.cmd run gas:init을 실행하세요.');
  }
}

function createUserError(message) {
  const error = new Error(message);
  error.userMessage = message;
  return error;
}
```
