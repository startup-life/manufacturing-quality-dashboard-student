# 1-4 보충: 첫 화면 주소 처리

## 필요한 동작

1-3에서 만든 제목 화면은 `/`와 `/inspections/abc`에서 모두 열려야 합니다. Express/Nest 라우트가 주소를 찾지 못해 404를 내면, `/api`가 아닌 화면 주소에 `public/index.html`을 보내도록 합니다. 이 단계에서는 제목만 보여 주고 로그인이나 뒤 회차 화면은 만들지 않습니다.

## 적용할 위치

`src/main.ts`에서 `public` 폴더의 정적 파일 제공을 먼저 설정하고, 그 뒤 `/api` 요청은 다음 처리기로 넘기며 나머지 화면 주소에는 `public/index.html`을 보내는 fallback을 둡니다. 화면 경로를 처리하는 Nest wildcard 라우트가 현재 Express 버전과 맞지 않으면 `sendFile`을 쓰는 미들웨어 fallback을 사용합니다.

화면 파일을 고친 뒤 새로고침하면 새 내용이 보이도록 `Cache-Control: no-store`를 유지합니다. `/api` 요청을 HTML fallback이 가로채면 안 됩니다.
