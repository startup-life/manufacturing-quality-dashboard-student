# 5-5 보충: NotebookLM 실행 환경과 빌드

서버가 실행 파일을 띄울 때 기본 환경은 유지하되 `ONEPORT_API_KEY`, `GAS_WEBAPP_URL`, `SESSION_SECRET`은 제외하고 `NOTEBOOKLM_HL=ko`, `NOTEBOOKLM_RATE_LIMIT_MAX_RETRIES=0`을 추가합니다. TypeScript에서는 복사한 환경 객체를 `NodeJS.ProcessEnv`로 선언한 뒤 비밀 값 키를 제외하면 타입 오류 없이 빌드할 수 있습니다.

MCP 초기화와 `notebook_query` 호출 순서, 150초 제한 및 오류 문구는 `docs/guide/session-5.md`의 「NotebookLM 도구 부르기」를 따릅니다. 이 단계에서는 도구를 실행하거나 실제 질문을 보내지 않습니다.
