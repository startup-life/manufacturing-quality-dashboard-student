# 5-17 보충: NotebookLM 근거 질문 수정본

설정의 Gemini 판독 지시문과 별도로 `NotebookLM 근거 질문` 선택·편집·수정본 저장 칸을 둡니다. 처음 선택은 v3이며 v1~v3 원문은 `prompts/notebooklm-v1.md`~`notebooklm-v3.md`입니다.

`GET /api/prompts?kind=notebooklm`은 근거 질문의 원문과 수정본만 반환하고, `POST /api/prompts`는 `base`, `text`, `kind: "notebooklm"`을 받아 수정본을 `runtime/custom-prompts.json`에 저장합니다. `kind`가 없는 기존 수정본과 종류를 생략한 요청은 기존처럼 Gemini로 취급합니다. 저장한 수정본 이름은 기반 버전과 `수정본`을 포함하고 설정 선택 목록에 바로 나타나야 합니다.

검사 상세 3번 탭의 질문 목록도 같은 NotebookLM 목록을 읽습니다. 선택한 수정본을 근거 확인 요청에 전달하고, 답의 `NotebookLM에 보낸 질문 보기`에 실제 사용한 수정본 이름을 보여 줍니다. Gemini 지시문 목록과 NotebookLM 질문 목록이 섞이지 않게 합니다.

직전 5-16 상태에서 원래 5-17 프롬프트를 적용한 뒤 설정에서 v3에 연습 문장을 더해 저장합니다. 생성된 수정본을 3번 탭에서 선택해 근거 확인하고, 보낸 질문의 사용 이름이 방금 저장한 수정본인지 확인합니다. 이전 Gemini 수정본도 기존대로 보이는지 확인합니다.
