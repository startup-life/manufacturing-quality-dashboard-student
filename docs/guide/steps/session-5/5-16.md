# 5-16 홈 "보고서 검토 대기"

이 문서는 5-16 프롬프트에만 적용합니다.

## 구현 보충

- 홈 숫자와 `review=pending` 목록은 같은 최신 결과 기준을 씁니다. 최신 판독 결과가 없으면 검토 대기에 세지 않습니다.
- 최신 결과의 제품·중량·사진이 현재 검사 정보와 다르면 검토 대기에 포함합니다.
- 최신 결과에 붙은 마지막 출처 대조 기록을 확인합니다. `VERIFIED_BY_USER` 또는 `MOCK_USER_REVIEWED`이면 검토 대기에서 빼고, 기록이 없거나 검토 필요이면 포함합니다.
- 실시간 저장에서는 `gemini_results`와 `evidence_links`를 함께 읽습니다. 연습용 저장에서는 `runtime/gemini-results.json`과 `runtime/evidence-links.json`을 읽습니다.
- 홈 `review_pending` 숫자와 검사 목록 `review=pending` 모두 위 계산을 사용합니다.
