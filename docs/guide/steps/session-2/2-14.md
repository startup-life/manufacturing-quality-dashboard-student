# 2-14 설정: 저장소 표시

이 문서는 2-14 프롬프트에만 적용하는 보충 기록입니다. 다른 단계의 기능을 앞당기지 않습니다.

## 구현 메모

- `GET /api/operations`는 로그인한 뒤 사용할 수 있게 Nest 컨트롤러로 만듭니다. 2회차 응답은 `{ "storage": "mock", "label": "내 컴퓨터" }`입니다.
- `/settings` 화면을 열 때 이 주소를 불러와 `저장소 상태` 칸에 `저장소: 내 컴퓨터`를 표시합니다.
- 서버 코드를 바꾼 뒤에는 `npm.cmd run build`로 빌드합니다. 이미 4185 포트에서 서버가 실행 중이면 그 앱 서버를 다시 시작한 뒤 브라우저에서 다시 확인합니다. 이전 서버가 계속 떠 있으면 새 API가 등록되지 않아 `/api/operations`가 404로 보일 수 있습니다.
