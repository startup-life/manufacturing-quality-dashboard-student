# 교육용 텀블러 검사기준 — Rev.B

문서번호: TUM-QC-STD-001 · 적용 버전: Rev.B · 용도: 가상 교육 실습

원본: standards/Rev.B.json. 가상 훈련 기준이며 실제 제조 규격이 아닙니다.

## 0. 변경 사항

Rev.A에서 은색 제품 중량 상한만 355g에서 354g으로 변경합니다. 다른 규칙은 유지합니다. 질의에서 적용 버전을 명시하며 두 버전을 혼합하지 않습니다.

## 1. 중량 기준

실측값 또는 교재 제공값만 사용합니다. 사진으로 중량을 추정하지 않습니다.

| 제품 ID | 허용 중량(g) |
| --- | --- |
| P-SILVER | 345 이상 354 이하 |
| P-WHITE | 445 이상 455 이하 |
| P-BLACK | 545 이상 555 이하 |

## 2. 외관 기준

명확한 스크래치·찍힘·라벨 오정렬·뚜껑 들뜸은 NG입니다. 가림·반사·해상도 부족으로 단정할 수 없으면 HOLD입니다. 사진으로 누수·중량·라벨 문구 적합성을 확정하지 않습니다.

## 3. 조치 기준

NG/HOLD → 작업중지 권고 → 관리자 확인(시뮬레이션). 설비 제어 및 출하 승인은 없습니다.

## 4. 응답과 출처

응답 항목은 판정, 불량유형, 관찰·수치 근거, 적용 기준과 출처, 권고 조치, 사람 승인 필요 여부입니다.

출처는 실제로 제공된 문서번호·버전·항목번호를 사용합니다. 예: TUM-QC-STD-001 Rev.B §1 중량 기준. Rev.A와 Rev.B를 섞어 적용하지 않습니다. 외관 OK는 중량·누수·라벨 문구·출하 승인까지 확인했다는 의미가 아닙니다.

외관에 문제가 보이지 않더라도 중량이 미측정이면 종합 정상 판정을 하지 않습니다. 필수 근거가 부족하면 HOLD로 보류합니다. AI 초안과 사용자 최종 기록은 구분하며 사람이 확인합니다.
