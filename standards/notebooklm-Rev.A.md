# 교육용 텀블러 검사기준 — Rev.A

문서번호: TUM-QC-STD-001 · 적용 버전: Rev.A · 용도: 가상 교육 실습

원본: standards/Rev.A.json. 가상 훈련 기준이며 실제 제조 규격이 아닙니다.

## 1. 중량 기준

실측값 또는 교재 제공값만 사용합니다. 사진으로 중량을 추정하지 않습니다.

| 제품 ID | 허용 중량(g) |
| --- | --- |
| P-SILVER | 345 이상 355 이하 |
| P-WHITE | 445 이상 455 이하 |
| P-BLACK | 545 이상 555 이하 |

## 2. 외관 기준

명확한 스크래치·찍힘·라벨 오정렬·뚜껑 들뜸은 NG입니다. 가림·반사·해상도 부족으로 단정할 수 없으면 HOLD입니다. 사진으로 누수·중량·라벨 문구 적합성을 확정하지 않습니다.

### 2.1 관찰 항목

- 스크래치: 표면에 명확하게 관찰되는 긁힌 흔적입니다. 반사광만으로 긁힘을 확정하지 않습니다.
- 찍힘: 표면의 명확한 국소 변형입니다. 각도·가림 때문에 확인할 수 없으면 추가 사진을 요청합니다.
- 라벨 오류: 명확한 라벨 오정렬을 관찰합니다. 읽을 수 없는 문구를 추측하지 않습니다.
- 뚜껑 조립 오류: 명확한 들뜸을 관찰합니다. 사진만으로 밀폐·누수 여부를 확정하지 않습니다.

이 설명은 기존 외관 기준의 관찰 안내입니다. 새로운 길이·깊이·기울기 허용치를 설정하지 않습니다.

## 3. 조치 기준

NG/HOLD → 작업중지 권고 → 관리자 확인(시뮬레이션). 설비 제어 및 출하 승인은 없습니다.

## 4. 응답과 출처

응답 항목은 판정, 불량유형, 관찰·수치 근거, 적용 기준과 출처, 권고 조치, 사람 승인 필요 여부입니다.

출처는 실제로 제공된 문서번호·버전·항목번호를 사용합니다. 예: TUM-QC-STD-001 Rev.A §2 외관 기준. 출처나 기준이 없으면 확인이 필요하다고 밝히며 다른 버전의 기준을 대신 적용하지 않습니다.

외관에 문제가 보이지 않더라도 중량이 미측정이면 종합 정상 판정을 하지 않습니다. 필수 근거가 부족하면 HOLD로 보류합니다. AI 초안과 사용자 최종 기록은 구분하며 사람이 확인합니다.
