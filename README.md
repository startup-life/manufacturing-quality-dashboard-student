# manufacturing-quality-dashboard-student

텀블러 공장 품질관리 사이트를 6회차 수업에서 AI와 함께 만듭니다.
이 브랜치(`milestone-0`)는 1회차를 시작하는 출발점이라 코드가 없습니다.

## 브랜치

회차를 다 끝내지 못했으면 다음 회차를 시작하기 전에 그 회차의 브랜치를 받아 같은 출발선에서 이어 갑니다.

| 브랜치 | 상태 |
|---|---|
| `milestone-0` | 출발점(코드 없음) |
| `milestone-1` | 1회차 완료: 서버 뼈대와 로그인 |
| `milestone-2` | 2회차 완료: 검사 등록, 품질 현황, 내 컴퓨터 저장 |
| `milestone-3` | 3회차 완료: Google 저장(시트·드라이브) |
| `milestone-4` | 4회차 완료: Gemini 사진 판독 |
| `milestone-5` | 5회차 완료: 검사기준 대조, NotebookLM |
| `main` | 6회차 완료: 내 판단 기록과 완성본 |

## 브랜치 받기

```powershell
git clone https://github.com/startup-life/manufacturing-quality-dashboard-student.git
cd manufacturing-quality-dashboard-student
git switch milestone-2
```

`milestone-2` 자리에 원하는 브랜치 이름을 넣습니다. 이미 받아 둔 폴더에서는 `git fetch` 뒤에 `git switch <브랜치>`만 실행합니다.
코드가 있는 브랜치(`milestone-1`부터)의 설치·실행 방법은 그 브랜치의 README에 있습니다.
